# 고혈압 메틸화 학습자료 재평가

GSE193795 고혈압44명·대조44명을 모두 학습한 뒤 같은88명을 평가했다. 전고혈압44명은 제외했다.
기존 최종 모델의 내부 교차검증 선택 파라미터를 고정해 새로4회 적합했다. 학습 AUROC는 resubstitution 적합도이며 독립 검증 성능이 아니다.
