# 고혈압 DNAm 신규 구현의 관측 결과

공개자료 수집, 품질관리, 학습 누출을 통제한 분류 파이프라인과 검증 산출물 생성은 완료하였다. 그러나 **이번에 사전 지정한 모델·자료·검증 설계에서는 임상적으로 유용한 고혈압 판별 성능을 확인하지 못하였다.** 과거 발표자료의 AUC 0.88을 이번 신규 분석의 결과로 승계하지 않는다.

개발 자료는 고혈압 44명과 대조 44명이며, 전고혈압 44명은 학습·특징 선택·튜닝에서 제외하였다. 원본 처리 자료 223,945개 CpG 모델과 독립 27k 자료에 적용 가능한 공통 10,749개 CpG 모델을 각각 평가하였다. 모든 학습된 결측 처리·특징 선택·스케일링·튜닝은 해당 훈련 fold 내부에서 수행하였다.

| 사전 지정 모델 | 주요 nested 5-fold AUROC | 95% 조건부 구간 | Brier |
|---|---:|---|---:|
| 공통 CpG ridge | 0.468 | 0.343–0.580 | 0.305 |
| 공통 CpG elastic net | 0.541 | 0.426–0.650 | 0.291 |
| 처리 자료 전체 CpG ridge | 0.432 | 0.312–0.560 | 0.303 |
| 처리 자료 전체 CpG elastic net | 0.569 | 0.448–0.696 | 0.283 |

주요 nested 5-fold 결과의 AUROC 구간은 모두 0.5를 포함한다. 균형 case-control 자료에서 모든 관측 Brier 점추정은 일정 확률 0.5를 출력하는 기준값 0.25보다 높았다. 보조 nested LOOCV에서도 개선이 일관되지 않았다. 전체 CpG ridge의 LOOCV AUROC는 0.366(조건부 구간 0.250–0.489)으로 낮았으며, 이 결과를 제외하거나 예측 방향을 사후 반전하지 않았다.

독립 GSE42774의 16개 시료에 대한 공통 CpG ridge/elastic net AUROC는 각각 0.562/0.641이었다. 그 조건부 구간은 각각 0.219–0.875/0.312–0.922로 넓다. 특히 사전 지정한 임계값 0.5에서는 **두 모델 모두 16명을 양성으로 판정하여 민감도 100%, 특이도 0%**였다. 이를 독립 자료에서 성공적인 질환 판별이나 임상 일반화가 입증된 것으로 해석할 수 없다. 연령·성별·집단·플랫폼 차이와 작은 표본수도 남아 있다.

AUROC·PR·Brier의 모든 구간은 1,000회 bootstrap으로 계산하였다. 내부 평가에서는 실현된 참가자 OOF 예측을 층화 재표집하고, 외부 평가에서는 공개된 8개 matched pair를 재표집했다. 이는 예측을 고정한 **조건부 구간**으로, 전체 CV·모델 선택을 반복한 불확실성을 포함하지 않는다. 민감도·특이도에는 exact binomial 구간을 사용했다. 모델 확률은 case-control 연구 점수이며 개인의 발병 위험률이나 식이 반응률이 아니다.

fold별 CpG 선택 빈도와 표준화 계수 방향은 탐색적 결과로 보존하였다. 검증된 임상 마커 200건, 새롭게 모집한 대상자 2,000명 또는 약 2,700명의 코호트 성과로 대체 계산하지 않는다. 공개 GSM 총 148건은 개발 88건·보조 44건·탐색적 외부 16건이라는 서로 다른 용도를 합친 자료 정리 규모이다.

현재 결과를 본 뒤 외부 자료나 LOOCV 결과에 맞춰 특징 수·규제 강도·임계값을 변경하지 않는다. 다음 연구 단계에서는 새로운 독립 코호트와 개별 공변량, 원시 IDAT 재처리의 필요성을 검토하고, 새 개발 분석과 기존 고정 평가를 구분해야 한다. 식품 성분 DTI와 식이 오믹스 근거는 독립 연구 모듈로 사용할 수 있지만, 이번 DNAm 판별 결과를 개인 맞춤 영양 효과의 근거로 사용하지 않는다.
