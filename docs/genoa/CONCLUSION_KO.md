# 독립 GENOA 혈압 대리 라벨 평가의 관측 결과

원래 개발 코호트의 고혈압44명·대조44명으로 학습한 ridge와 elastic net을 변경하지 않고, 독립 공개 GSE157131/GPL13534 혈액 백혈구 DNAm 자료에 적용하였다. 공개272명의 혈압으로 사전 정의한 상승혈압126명·정상혈압53명을 평가했고, 중간혈압93명은 이진 평가에서 제외했다. 상승혈압은 수축기≥140 또는 이완기≥90, 정상혈압은 수축기<120 및 이완기<80으로 정했다.

| 고정 모델 | 평가179명 AUROC | 95% 조건부 구간 | Brier | 민감도 | 특이도 |
|---|---:|---|---:|---:|---:|
| Ridge | 0.551 | 0.453–0.641 | 0.252 | 0.516 | 0.604 |
| Elastic net | 0.516 | 0.410–0.614 | 0.234 | 0.968 | 0.057 |

성능을 관측하기 전에 지정한50–65세 보조 대상67명에서는 ridge AUROC0.488(구간0.343–0.633), elastic net0.545(구간0.398–0.699)였다. 네 AUROC 구간 모두0.5를 포함한다. **이번 독립 자료 추가로 고혈압 판별 성능 개선이나 임상 일반화를 확인하지 못하였다.** 두 모델을 모두 보고하며, 유리한 가족·연령·임계값·프로브·예측 방향을 사후 선택하지 않았다.

공통10,749개 학습 입력 중10,689개가 대상 자료에 제공되었고60개는 제공되지 않았다. Ridge의 선택100개 중4개, elastic net의 선택500개 중11개가 미제공이다. 이 부분은 예측을 생성하기 전에 프로토콜을 수정해 명시했다. 원본 입력 위치를 모두 유지하면서 미제공값을 NaN으로 표시했고, 기존 학습88명에서 정한 중앙값만 적용했다. 대상 코호트의 중앙값·배치·분산·결측률로 모델을 다시 맞추지 않았다. 측정된10,689개 CpG에서는272명 모두 추가 detection-P/신호 실패가 관측되지 않았고, 표본을 결측률에 따라 제외하지 않았다. 따라서 이 결과는 일부 입력이 미제공된 고정 모델의 탐색적 배포 평가이며 완전한 프로브 커버리지 검증은 아니다.

대상 혈압은 임상 고혈압 진단과 같은 라벨이 아니다. 개인의 약물복용 여부와 공개 혈압값의 약물 보정 여부를 확인할 수 없어, 치료된 고혈압 환자가 정상혈압 대리군에 포함될 수 있다. 개인 가족 ID도 없어 가족 내 의존성을 모델링하지 못했다.1,000회 참가자 bootstrap 구간은 고정 예측에 조건부이며, 가족 의존성이나 전체 모델 선택의 불확실성을 포함하지 않아 불확실성이 과소평가될 수 있다. 연령·성별은 기술통계만 제시했고 조정을 수행하지 않았다.

평가 자료의 상승혈압 비율은126/179=0.704이므로 AP의 유병률 기준도0.704이다. Elastic net AP0.704는 이 기준과 비슷하다. Brier0.234는 상수0.5 출력 기준0.25보다 작지만, 평가 자료의 경험적 사건비율을 상수로 사용하는 기술적 기준값0.208보다 크다. 이 경험적 기준은 평가용 비교값으로만 계산했으며 예측이나 모델 재보정에 사용하지 않았다. 선택된 극단 혈압 대리군의 확률을 개인 발병 위험률로 해석할 수 없다.

원래 임상 라벨 개발 자료의 nested5-fold·LOOCV,88→16 및16→88 전이 결과는 그대로 보존한다. 새로운 결과가 기존 AUC0.88 주장이나 임상 검증 마커 성과를 대신하지 않는다. 연구 성과는 자료 수집·누출 통제·고정 모델의 독립적 평가·실제 실패 결과를 보존하는 재현 가능한 구현이다.
