This directory contains the S-BSST831 repository raw-beta experiment and its
derived receipts. Completion requires both `summary.json` with all four
declared endpoints and `audit.json` with `all_16_results_passed=true` and a
matching `summary_sha256`. Endpoint files alone are interim results.

The input has 255 participants and 731,635 CpGs. The verified downloaded raw
file is 3,381,823,154 bytes, SHA256
`cacaf984aa56cb4761a9eff6c270c875411f6717cbf4d35836e72d8b0e1b7cc6`,
CRC32 `60340564`. These are locally generated byte-integrity checksums; the
official source did not publish a checksum. All 404 verified ranges cover the
file exactly once. The original IDAT/detection-P processing cannot be repeated
from this source-provided beta export. No new cohort-wide quantile
normalization or ComBat is applied.

The endpoints are CS-versus-primary-HTN (99 people), PA-versus-primary-HTN
(143), PPGL-versus-primary-HTN (97), and combined endocrine
CS+PA+PPGL-versus-primary-HTN (255). The frozen ID `EHT_vs_PHT` denotes the
last combined endocrine endpoint. All comparisons reuse the same 42 primary
hypertensive controls; they contain zero healthy controls and are not separate
external studies. Do not sum their participant counts.

Recruitment centers are held out in three outer folds, with two inner and
calibration folds within outer training centers. Missingness filtering,
imputation, CpG selection, scaling, regularization choice and calibration are
training-only. Ridge, elastic net and linear SVM use the fixed
`k={10,50,200,1000}`, `C={0.01,0.1,1,10}` grids. A fixed-C1 age/sex comparator
uses the same outer center memberships; it does not constitute age/sex
adjustment of methylation models. Center and subtype are strongly confounded.

Discrimination and Brier confidence intervals use recruitment-center cluster
bootstrap conditional on the fixed OOF predictions, excluding retraining and
split uncertainty. Sensitivity/specificity use participant-level exact
intervals and do not incorporate center clustering. All models and endpoints,
including weak results, remain in the comparison.

The result audit recomputes AUROC by the tie-aware rank statistic and Brier
score directly from each fixed OOF table. It verifies outer patient/center
memberships against the actual metadata preflight, inner/calibration center
disjointness, full input and metadata hashes, executed code snapshots and all
16 expected model/endpoint rows. It fits or selects no model.

From the repository root, run the final audit after collecting all completed
derived outputs:

```text
python scripts/audit_endocrine_outputs.py --directory docs/endocrine_extension_20261003_v1 --metadata-preflight docs/phase1_extension_receipts_20261003/endocrine_metadata_fold_preflight.json --acquisition docs/endocrine_acquisition_complete_20261003_v1/range_acquisition_status.json --output docs/endocrine_extension_20261003_v1/audit.json
python scripts/package_extension_results.py --output docs/phase1_extension_receipts_20261003
```

All 16 evaluations are now complete and independently audited. The highest
methylation AUROC is 0.6437 (CS versus primary HTN, ridge); no declared
methylation model reaches AUROC >0.8. These negative results remain unchanged.

`comparison.tsv` is the separate, final 16-row endocrine table. The default
packaging command above preserves the original 14-row extension table used by
the report. To create a distinct combined 30-row package after the independent
audit passes and its summary hash matches, run:

```text
python scripts/package_extension_results.py --output docs/phase1_extension_all30_20261003 --include-endocrine
```

The original 14-row output directory rejects `--include-endocrine`. Raw matrix NPZ, native clinical
metadata table and fitted weight files are not included in this collected
derived-output directory.
